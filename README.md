# Sajid Kabir Saji

Engineer, builder and wanderer. I build open-source Python tools for drone autonomy, flight physics, and aviation data. Every project ships with a full automated test suite, CI, and honest documentation of its own limitations.

My research focus is onboard autonomous decision-making for drones: aircraft that perceive their surroundings, evaluate options, and act on their own. Solar-electric endurance is a complementary line of work, growing out of my undergraduate thesis on a solar-powered quadcopter.

## Projects

| Project | What it does |
| --- | --- |
| [solar-uav-sim](https://github.com/sajidkabir/solar-uav-sim) | Solar UAV endurance simulator: 24-hour energy balance and charge-consumption parity analysis |
| [drone-autonomy-sim](https://github.com/sajidkabir/drone-autonomy-sim) | Onboard autonomy simulation: A* path planning, in-flight replanning, battery-aware return-to-home decisions, explainable decision log |
| [counter-uas-sim](https://github.com/sajidkabir/counter-uas-sim) | Counter-drone defence simulation: detection, Kalman tracking, threat scoring, low-cost interceptor guidance, Monte Carlo cost analysis |
| [isa-aero](https://github.com/sajidkabir/isa-aero) | International Standard Atmosphere and aerodynamics utilities for flight simulation and UAV design |
| [metar-decoder](https://github.com/sajidkabir/metar-decoder) | METAR aviation weather decoder: raw reports parsed into structured, human-readable data |
| [naca-airfoil](https://github.com/sajidkabir/naca-airfoil) | NACA 4-digit airfoil generator and analyzer: coordinates, thin-airfoil theory, exports |
| [drone-mission-planner](https://github.com/sajidkabir/drone-mission-planner) | Multirotor mission planner: waypoints, geofence checks, and energy feasibility verdicts |
